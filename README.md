# Pembukuan Rental PS — URBAN GAMING LAMPUNG (Vite + React + TS + Tailwind)

## Cara Jalankan
1. Pastikan sudah terinstal **Node.js 18+** dan **pnpm** atau **npm**.
2. Extract zip ini.
3. Buka folder di terminal:
   ```bash
   cd pembukuan-urban
   ```
4. Install dependencies:
   ```bash
   npm install
   # atau
   pnpm install
   ```
5. Jalankan mode pengembangan:
   ```bash
   npm run dev
   ```
6. Buka URL yang muncul (biasanya `http://localhost:5173`).

## Build produksi
```bash
npm run build
npm run preview
```

## Catatan
- Tombol **📝 Download Laporan** men-generate PDF dengan screenshot satu halaman penuh.
- Tombol tema **🌙 / ☀️** switch dark/light (default **dark**).
- Pengaturan berisi tombol **📝 Edit Rincian** (contoh placeholder di preview).
